## 1. 背景与目标

### 1.1 背景

孩子在平板上练拼音和写字，现有工具都不合适：

- **实体字帖**：买一本写几天就写完，写完即废，无法重写、无法留存。
- **备忘录/笔记类 App**：笔迹有明显延迟和拖影，没有田字格/四线三格，更没有描红底字。
- **在线教育 App**：需要登录和联网，体积大、有广告和付费墙，平板上的「离线随手写」需求被忽略。

家里已有安卓平板，缺的只是一个「装上就能写、写得跟手、有格子有描红」的轻量工具。

### 1.2 产品定位

给 5–8 岁孩子的**离线格子本 + 描红字帖**，一个 PWA：装到桌面、全屏打开、断网可写、无账号无广告。

### 1.3 产品目标

| # | 目标 | 说明 |
|---|---|---|
| G1 | 打开即写 | 从点桌面图标到落笔，最多 3 次操作，中途无弹窗、无空状态页 |
| G2 | 跟手 | 主观感受「笔跟着手走」，不断线、不拖影、不跳点 |
| G3 | 写不错位 | 平板平放时手掌压屏不产生乱线（笔模式） |
| G4 | 不丢作品 | 关闭页面、切后台、锁屏后重开，内容完整保留 |
| G5 | 可离线 | 飞行模式下全功能可用（字帖、书写、导出） |
| G6 | 可留存 | 能把一页导出成图片发给家人，能整本备份到文件 |

### 1.4 成功指标（V1.0 验收口径）

| 指标 | 目标值 | 测量方式 |
|---|---|---|
| 首笔响应延迟 P95 | ≤ 32ms | 从 `pointerdown` 到首帧绘制完成（代理指标，见 TECH §5） |
| 连续书写平均帧率 | ≥ 55 FPS | 中端基准机型连续写 60 秒，`requestAnimationFrame` 计时采样 |
| 笔迹断线率 | 0 | 快速连笔 100 次，目视无断裂 |
| 异常退出后数据完整率 | 100% | 落笔后 3 秒内强杀进程，重开后笔画数一致 |
| 冷启动到可书写 | ≤ 1.5s | PWA 二次启动、基准机型 |
| 儿童可用性 | 3 名 5–8 岁儿童中 ≥ 3 名无需指导完成「打开→写满一行→擦掉重写」 | 现场走查 |

### 1.5 非目标（V1.0 明确不做）

- **不做**账号体系、后端、云同步、多端同步
- **不做**笔画顺序动画演示、自动评分、AI 判字
- **不做**混合格子（上拼音下田字）
- **不做** iOS / iPad / Safari 适配
- **不做**文本输入、键盘、富文本
- **不做**像素级橡皮擦（只做整笔擦除）
- **不做**多孩子档案、家长管控、打卡统计

## 2. 用户与场景

### 2.1 用户角色

| 角色 | 特征 | 关键诉求 | 使用频率 |
|---|---|---|---|
| **孩子（主使用者）** | 5–8 岁，识字有限，手指操作不稳 | 打开就能写；写错了能擦掉；格子和底字看得懂；不要太小的按钮 | 每日 |
| **家长（安装者/管理者）** | 负责装 App、检查作业、备份数据 | 一次装好不用管；没有广告和内购；能把作品导出来 | 每周 |

> 设计取向：界面元素按钮 ≥ 48×48 CSS px，图标优先于文字，不放置需要阅读长文本才能操作的入口。

### 2.2 核心场景

**S1 · 每日练拼音**
打开桌面图标 → 直接进入上次的页面 → 点「新建」选「拼音字帖 · 声母」→ 前 3 格是浅色底字，照着描 → 后面空格自己写 → 写错点橡皮擦掉那一笔。

**S2 · 抄写汉字**
新建「汉字字帖 · 一年级常用字」→ 每行第一个是示范字、第二三个是描红、其后空白 → 一行写完翻到下一个字。

**S3 · 自由涂写**
新建「空白田字格」页 → 随便写画 → 不保存也没关系，退出自动留在本子里。

**S4 · 分享作品**
在页列表长按一页 → 「导出图片」→ 图片存到平板相册 → 家长发到家庭群。

**S5 · 换设备备份**
「更多 → 导出备份」得到一个 JSON 文件 → 在新平板安装后「导入备份」→ 页面全部恢复。

### 2.3 使用环境与约束

| 维度 | 约束 |
|---|---|
| 设备 | 8–13 寸安卓平板，横屏与竖屏都会用 |
| 浏览器 | Android Chrome 稳定版（Android 10+） |
| 输入源 | 手指为主；若配主动笔则需支持真实压感 |
| 网络 | 家庭环境，可能无稳定网络 → 全功能离线 |
| 姿势 | 平板平放或立起，孩子单手握笔，另一只手/手腕必然压屏 → **手掌过滤为刚需** |
| 干扰 | 孩子会误触边缘、会快速乱画、会连点按钮 → 需要防误触与防重复提交 |

### F1 · 格子页渲染与布局

#### F1.1 页面类型

V1.0 只支持两种格子，**不做混合格子**：

| 类型 | 标识 | 视觉规范 |
|---|---|---|
| 田字格页 | `tianzi` | 正方形方格阵列；每格为 **浅色实线外框 + 横竖两条虚线中线**（中线在格中心十字交叉） |
| 米字格页 | `mizige` | 在田字格基础上增加 **两条虚线对角线**（左上→右下、右上→左下），几何与田字格完全一致 |
| 四线三格页 | `pinyin` | 水平条带阵列；每条包含 **4 条等距水平线**，形成 3 个横向区域 |

四线三格的线语义必须与教学一致，不可混用：

| 线序 | 名称 | 样式 | 用途 |
|---|---|---|---|
| 第 1 线 | 上线（顶线） | 浅色实线 | 上格上边界，升部字母（b d h k l）的顶端 |
| 第 2 线 | 中格上沿 | 浅色虚线 | 小写字母主体（a c e o）的上沿 |
| 第 3 线 | **基线** | **较深实线** | 字母的落脚线，最关键的参考线 |
| 第 4 线 | 下线 | 浅色实线 | 下格下边界，降部字母（g p q y）的底端 |

- 线条颜色使用柔和暖色（默认 `#d98b8b` 系），中线/虚线更浅，避免与笔迹争夺注意力。
- **线宽固定 1 CSS px**，按 `devicePixelRatio` 换算，保证高分屏下不发虚、不发粗。
- 格子层是纯装饰，**不参与命中检测**，不做书写区域裁剪（孩子写出去是正常行为）。

#### F1.2 自适应布局

- 页面**不滚动**，整页固定视口高度，书写区禁用浏览器滚动与缩放。
- 田字格页 / 米字格页：格子始终保持**正方形**，按可用区域自动计算列数与行数，剩余空间**垂直居中留白**，不允许出现半格；两者格数与格尺寸必须完全一致，切换类型不改变布局。
- 四线三格页：条带高度由单格高度 `u` 决定（总高 = 3u），条带之间留 `u` 的间距；横向贯通整个可用宽度，**不画竖分隔线**。
- 横竖屏切换、窗口尺寸变化时重新计算并重绘格子层，已书写笔迹按**相对坐标重新映射**，不得错位或丢失。

#### F1.3 边界规则

- 任一方向可容纳格数 < 最小值时（如小窗模式），按最小格数渲染并允许底部被裁切，优先保证格子不变形。
- 停止书写与重新布局不应导致当前页数据变更。

### F2 · 手写输入与笔迹渲染

#### F2.1 输入

- 统一使用 Pointer 事件采集，**手指、触控笔、鼠标走同一套逻辑**。
- 必须补齐浏览器合并的高频采样点，避免快速书写时出现折线/断点。
- 坐标需按画布实际像素比换算，保证手指落点与笔迹起点重合（不允许出现斜向偏移）。
- 书写区禁用浏览器默认手势（滚动、缩放、长按选择）。

#### F2.2 笔迹表现

| 项 | 规范 |
|---|---|
| 颜色 | 默认 `#2b2b2b` 深灰（比纯黑柔和）；P1 提供 2–3 种柔和色 |
| 线宽 | 细 / 中 / 粗三档，默认中（基础线宽 3 CSS px，起收笔与转折处随速度或压感变化） |
| 笔锋 | 慢粗快细；若设备提供真实压感则以压感优先，速度模拟作为兜底 |
| 平滑 | 采用曲线插值，禁止出现明显折角；相邻采样点过近时去重 |
| 断线 | 同一笔内不得断开；抬笔后才允许出现笔画间隙 |
| 收笔 | 抬笔瞬间补齐到最后一个采样点，不得出现「提前断尾」 |

#### F2.3 边界规则

- 单笔最多保留 2000 个采样点，超出后按距离抽稀，不影响观感。
- 手指按下但未移动（点状轻点）也应产生一个可见圆点，而不是无响应。
- 多指同时按下时，仅第一根按下的手指/笔产生笔画，其余忽略直至抬起。

### F3 · 笔模式（手掌防误触）

#### F3.1 规则

- **首次检测到 `pointerType === 'pen'` 时自动进入笔模式**，此后所有非 `pen` 的按下/移动事件一律丢弃，不进入笔迹采集。
- 笔模式只作用于**书写区**；顶栏、底栏、弹层等 UI 元素**必须继续接受手指点击**，否则孩子无法退出。
- 必须提供**显式的「退出笔模式」按钮**（手指在书写区无法反向退出笔模式）。

#### F3.2 状态

- 笔模式状态需在当前会话内保持，切换页面不重置。
- 退出笔模式后恢复手指书写。
- 顶栏需有**持续可见**的笔模式指示（如铅笔图标高亮），让孩子/家长一眼看出当前状态。

#### F3.3 边界规则

- 笔模式下若主动笔离开屏幕超过一定时间（如 5 分钟无笔输入），**不自动退出**，避免误判；只能手动退出。
- 未检测到主动笔的设备（纯手指书写）不得进入笔模式。

### F4 · 撤销 / 重做 / 整笔擦除

#### F4.1 撤销与重做

- 粒度：**以一笔为单位**（含擦除操作），不做逐点撤销。
- 撤销栈深度 30 步；产生新的书写/擦除后清空重做栈。
- 每页维护独立栈；切换页面时保留当前页栈，切走后栈可丢弃。
- 无操作可撤销时，按钮置灰且点击无反馈噪音。

#### F4.2 整笔擦除

- 擦除对象是**整笔**，不是像素。
- 判定方式：手指/笔尖落点距离某笔画路径足够近时，命中该笔；若同时命中多笔，删除**距离最近的一笔**。
- 命中容差随当前笔宽自适应（约 12 CSS px）。
- 擦除后笔迹立即从已完成层消失，且**不重绘整页**。

#### F4.3 边界规则

- 擦除属于可撤销操作，孩子误擦可以撤销回来。
- 擦除工具只在书写区生效，不响应 UI 区域。
- 擦除过程中不允许拖动产生多笔连擦（V1.0 单次点击擦一笔，避免误删）。

### F5 · 多页管理

#### F5.1 页面模型

- 一个「本子」包含 N 页，**按创建顺序排列**，最新页在最后（像真实本子往后翻）。
- 每页独立保存：格子类型、列数/行数、内容类型（空白/字帖）、笔迹数据。
- 每页有标题，默认按类型自动生成（如「田字格 3」「拼音字帖 10-27」），V1.0 不支持重命名（P1）。

#### F5.2 新建页

- 入口：底栏「+」按钮 → 弹出页面类型选择（空白田字格 / 空白米字格 / 空白四线三格 / 拼音字帖 / 汉字字帖）。
- **新建页继承当前页的格子类型与列数**，减少选择成本。
- 新建后立即切换并聚焦到新页，可马上书写。

#### F5.3 页面切换

- 入口：底栏左右箭头翻页；点击标题打开页列表。
- **不使用左右滑动手势翻页**（会与书写/擦除手势冲突）。
- 翻页到首/末页时对应箭头置灰。
- 切换前必须先提交当前未完成的笔画，不允许跨页残留。

#### F5.4 页列表

- 以缩略图网格展示全部页面，当前页高亮。
- 缩略图在页面保存时生成，需能辨认出大致书写内容。
- 列表可删除单页（**二次确认**）；删除最后一页后自动新建一页空白页，避免出现空本子。
- 列表需展示每页标题与最后修改时间。

#### F5.5 首次启动

- 首次启动（本地无数据）时**自动创建一页空白田字格**并直接进入书写区。
- 不出现引导页、教程弹窗、空状态插画。

### F6 · 本地持久化与异常保护

#### F6.1 存储

- 全部数据保存在设备本地浏览器存储中，**不联网、不上传**。
- 写库时机：抬笔后延迟合并写入，同时对持续书写做上传上限节流（不允许每帧写库）。
- 强制落盘时机：页面隐藏、切到后台、页面卸载、翻页、退出书写区。
- 启动时恢复上次打开的页面（记录「当前页」）。

#### F6.2 数据可靠性

- 启动时向浏览器申请**持久化存储权限**，降低系统清理概率。
- 存储不可用（隐私模式、配额耗尽、数据库损坏）时：进入内存模式继续可写，并**明确提示用户导出备份**，不允许静默丢失。
- 单页笔迹数据量超过阈值时给出提示（引导新开一页），不得直接截断。

#### F6.3 边界规则

- 落笔后 ≤ 3 秒内强杀进程，重开后已落盘内容必须完整（以最后一次成功落盘为准）。
- 数据库版本升级需保留旧数据，不允许因 schema 变更清库。

### F7 · 导出与备份

#### F7.1 导出单页图片

- 输出 PNG，内容 = **格子层 + 全部笔迹**，不含工具栏与 UI。
- 分辨率 2 倍导出（长边不超过 2400px），保证放大可读。
- 默认保存为 `格子本-YYYYMMDD-HHmm.png`。
- 导出过程不得阻塞书写交互超过 100ms；若页面较大，需显示导出中状态。
- 相册写入依赖系统能力，若无法直接保存则降级为浏览器下载，并提示文件位置。

#### F7.2 导出整本备份

- 输出 JSON 文件，包含：应用标识、schema 版本、导出时间、全部页面（元数据 + 笔迹）。
- 文件名 `格子本备份-YYYYMMDD.json`。
- 导出前需确保所有页面数据已落盘。

#### F7.3 导入备份

- 校验应用标识与 schema 版本；不匹配时提示「备份文件格式不支持」，**不执行任何写入**。
- 导入的页面**生成新 id 追加到本子末尾**，不与现有页面冲突、不覆盖。
- 导入完成后提示「成功导入 N 页」，并停留在页列表让用户确认。
- 部分页面损坏时跳过损坏项继续导入，并在结果中告知跳过数量。

### F8 · 描红字帖

#### F8.1 字帖类型

| 类型 | 格子 | 内容 | MVP 内置字库 |
|---|---|---|---|
| 拼音字帖 | 四线三格 | 小写拼音字母 | 26 个小写字母（按声母/韵母分组）+ 声调练习（a/o/e 的四个声调） |
| 汉字字帖 | 田字格 | 常用汉字 | 两组一年级常用字：独体字 24 字、常用字 36 字，合计 60 字 |

- 字库以 **JSON 静态配置**管理，`{ id, name, gridType, cols, chars[] }`，新增字帖不需要改代码。
- 字帖页列数由字库定义（默认 6 列），不从当前页继承。

#### F8.2 描红呈现

- 底字为**浅灰/淡色实心字**（不透明度约 12%–18%），坐在格子中的标准位置，孩子直接描在上面。
- 底字必须使用**楷体风格字体**（手写规范字形），不使用默认黑体，避免教错笔形。
- 拼音底字需与四线三格参考线**视觉对齐**：以中格字母 `a / o / e` 为基准，字身底部贴第 3 线，误差 ≤ 2 CSS px。
- 汉字底字在格子内**按自身墨迹包围盒居中**：垂直方向偏差 ≤ 2 CSS px，墨迹高度约占格边长 70%–75%，四周留白均匀、不触边。
- 不得用 `textBaseline = 'middle'` 定位（汉字字形上紧下松，实测会整体偏低约 6px），必须按墨迹实测高度补偿基线。
- 底字属于格子层，**不可被覆盖或擦除**，随格子层一起重绘。

#### F8.3 行内结构

每行按固定角色排列，从上往下按字库条目逐行填充：

| 位置 | 角色 | 说明 |
|---|---|---|
| 第 1 格 | `demo` | **深色示范字**（约 55% 不透明度），看清字形 |
| 第 2–3 格 | `trace` | 浅色描红底字，孩子覆写 |
| 第 4 格起 | `blank` | 空白格，独立书写 |

- 单页可容纳行数不足时，**自动拆分到下一页**（生成连续的多个字帖页），保证同一字库的条目连续。
- 四线三格页不画竖分隔线，但 `demo/trace` 底字需按逻辑格宽度定位，横向间距一致。

#### F8.4 字帖选择

- 入口：新建页弹层中的「拼音字帖」「汉字字帖」。
- 选择器以**卡片列表**展示一个字库的全部条目（可见字形预览），点选即创建。
- 需展示字库名称与字数，便于家长辨认。

### F9 · PWA 安装与离线

#### F9.1 安装

- 提供 Web App Manifest：独立窗口显示（无地址栏）、固定主题色、192/512 及 maskable 图标。

#### F9.2 离线

- App 外壳（HTML/JS/CSS/字体/图标/字库 JSON）全部预缓存。
- **断网后全功能可用**：书写、切换页、字帖、导出、导入均不受影响。
- 首次访问需联网完成安装；安装后不得再依赖网络。

#### F9.3 显示与交互

- 独立窗口下全屏书写，禁止页面缩放与地址栏抖动。
- 横竖屏均可使用；旋转后布局与数据不丢失。

## 5. 数据模型

### 5.1 页面元数据（列表用，轻量）

```ts
interface PageMeta {
  id: string                 // uuid
  createdAt: number
  updatedAt: number
  title: string              // 自动生成
  gridType: 'tianzi' | 'mizige' | 'pinyin'
  cols: number
  rows: number
  kind: 'blank' | 'copybook'
  copybook?: CopybookMeta
  strokeCount: number
  thumbnail?: string         // 缩略图 dataURL
}
```

### 5.2 页面内容（按需加载）

```ts
interface PageContent {
  pageId: string
  strokes: Stroke[]
}

interface Stroke {
  id: string
  color: string
  width: number
  points: number[]           // 扁平存储：[x, y, pressure, t, ...]
}
```

> 元数据与笔迹**分表存放**：加载页列表只读元数据，打开某页才取笔迹，避免列表加载时搬运整本数据。

### 5.3 字帖结构

```ts
interface CopybookSource {   // 静态字库 JSON
  id: string
  name: string
  gridType: 'tianzi' | 'mizige' | 'pinyin'
  cols: number
  chars: string[]
}

interface CopybookMeta {
  sourceId: string
  sourceName: string
  rows: CopyRow[]            // 本页承载的行
}

interface CopyRow {
  char: string
  cells: ('demo' | 'trace' | 'blank')[]   // 长度 = cols
}
```

### 5.4 备份文件

```ts
interface BackupFile {
  app: 'grid-notebook'
  schemaVersion: 1
  exportedAt: number
  pages: { meta: PageMeta; strokes: Stroke[] }[]
}
```

### 5.5 坐标约定

- 笔迹点坐标以**归一化坐标（0–1）**存储，相对书写区尺寸，与设备像素比、屏幕物理尺寸无关。
- 渲染时按当前书写区大小换算为 CSS px，保证换屏、旋转、分屏后笔迹仍落在正确位置。
- 已知取舍：极端长宽比变化时字形会被等比拉伸。V1.0 接受该行为，仅要求「位置正确、数据不丢」。

## 8. 风险与对策

| # | 风险 | 影响 | 对策 |
|---|---|---|---|
| R1 | 安卓平板 DPR 与触控采样差异大，跟手性在低端机不达标 | 核心体验受损 | 建立基准机型清单；渲染分层 + 增量绘制；必要时降低平滑精度 |
| R2 | 楷体字体子集体积过大拖慢首屏 | 安装体验差 | 仅子集化字帖用字；woff2 + `font-display: swap`；字体异步加载不阻塞首屏 |
| R3 | 底字与四线三格对不齐（不同字体 metrics 差异） | 描红错位，教学错误 | 以 `a/o/e` 做基线校准常量；字帖渲染做视觉回归截图比对 |
| R4 | PWA 本地数据被系统清理 | 作品丢失 | 启动申请持久化存储；引导定期导出备份；异常时明确告警 |
| R5 | 主动笔压感在部分设备不可靠（始终返回 0.5） | 笔锋变成死线宽 | 检测压感方差，异常时自动回退速度模拟 |
| R6 | 长时书写内存增长（已完成笔迹层位图） | 卡顿/OOM | 限制单页笔画数与点数；必要时按区域分块提交 |
| R7 | 屏幕尺寸碎片化导致格子出现半格、布局跳动 | 观感差 | 只按整数格计算并居中留白；禁止小数格 |
| R8 | 字库字形正确性（非教学规范字形） | 教错笔形 | 字库人工校对；仅收录常用字；字体固定为楷体 |

## 10. 术语表

| 术语 | 含义 |
|---|---|
| 田字格 | 正方形内加十字中线的练字格 |
| 米字格 | 田字格再加两条对角线，形似「米」字，用于更精确的字形定位 |
| 四线三格 | 四条等距水平线构成的拼音书写区，字母坐在第 3 线（基线）上 |
| 描红 | 在浅色底字上覆写练习 |
| 笔模式 | 检测到触控笔后屏蔽手指/手掌输入的防误触模式 |
| 增量绘制 | 只绘制新变化区域/新笔画，不重绘整页 |
